# Islay, dram by dram

Trip guide for the 40th birthday whisky trip to Islay, 26 June to 2 July 2027.

This folder is the finished website. Netlify publishes it as it is, with no build step,
so every push to `main` goes live on the Netlify link within a minute or so.
It also installs on a phone as an app and works offline.
